# MadaSoft - Site vitrine

Site vitrine statique responsive pour présenter :
- Work Smart Mada
- StockSmart Mada
- FactureMada

## Fichiers

- index.html : structure du site
- style.css : design responsive + animations
- script.js : menu mobile, animations au scroll et formulaire email

## Lancer le site

Double-cliquez sur `index.html`.

Aucun serveur n'est nécessaire.

## Personnalisation importante avant publication

Dans `index.html`, remplacer :
- `contact@madasoft.mg`
- `Votre numéro professionnel`
- les tarifs indicatifs si nécessaire
- les textes de présentation
- le nom de marque si vous choisissez un autre nom

Le formulaire utilise `mailto:` : il ouvre le logiciel de messagerie du visiteur. Pour un formulaire réellement envoyé sans logiciel email local, il faudra ensuite connecter un service/backend.
